# Code of Conduct

## Our commitment

Homelab welcomes respectful participation regardless of background, identity, or experience. Everyone contributing to issues, pull requests, reviews, documentation, or project discussions is expected to follow this code.

## Expected behavior

- Be considerate, constructive, and patient. Critique code and decisions, not people.
- Explain technical disagreements with evidence and acknowledge mistakes.
- Respect people's time, boundaries, and privacy.
- Protect credentials and private infrastructure details, including in screenshots and logs.
- Clearly distinguish verified results from assumptions, including in AI-assisted contributions.

Harassment, discrimination, threats, personal attacks, sexualized behavior, and deliberate disruption are not acceptable. Do not publish another person's private information without their permission.

## Scope and reporting

This code applies in project spaces and when someone represents the project elsewhere.

Report conduct concerns privately to the repository owner, [@rajohan](https://github.com/rajohan), through an existing private contact channel. If you do not have one, ask for a private contact method without publishing sensitive details. Do not use a public issue to disclose private allegations or personal information.

Report software vulnerabilities through [SECURITY.md](SECURITY.md), rather than a public conduct report.

## Enforcement

The repository owner may remove inappropriate content and request a correction, issue a warning, restrict participation temporarily, or exclude a participant. The response should be proportionate to the behavior, its impact, and whether it is repeated. Serious threats or harassment can justify immediate restriction.

Reports should be handled discreetly; only information needed to investigate and respond should be shared. A concern about an enforcement decision may be raised privately with the repository owner. No response deadline is promised.

Maintainers are subject to the same conduct standards as other contributors.
